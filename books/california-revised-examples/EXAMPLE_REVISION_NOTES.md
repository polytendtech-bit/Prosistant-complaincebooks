# California book: scenario-only revision

The uploaded California book contains 1,000 exercises organized in 100 existing case families and 25 topics. This revision replaces only the Chinese and English scenario paragraphs. Questions, all answer sections, citations, titles, identifiers, notices, topic organization, setting classifications, CSS and JavaScript are unchanged. A full-document comparison after masking only the two scenario paragraphs in each card passed.

The replacement paragraphs present different factual issues: document conflicts, actual versus assumed authorization, specific handoff gaps, unsafe shortcuts, incomplete preparation, and unresolved observations. They are not created by changing names or timestamps in the old repeated story. Exact-text checks confirm 1,000 different English narratives and 1,000 different Chinese narratives.

That exact-text result does not mean the book now covers 1,000 distinct statutory requirements. The original 100-family/ten-task structure remains because all other content was to be preserved. Cases within a family still practice the same underlying principle through different facts and decision contexts. The behavior-record family retains the necessary Ava/truck/block premise because its unchanged answers explicitly refer to it; the record issue differs in each scenario. The possible-duplicate-dose family retains the non-emergency condition so its unchanged answer is not used as acute medical advice.

No new legal requirements, subsection identifiers, deadlines, dosage instructions or verification claims were added. The pre-existing legal-verification limitations and citations are unchanged. This work replaces narratives within the existing framework; it does not complete the separately blocked subsection-by-subsection regulatory review. Any future change to the actual regulatory coverage will require corresponding revisions to questions, answers and source mapping rather than a scenario-only edit.

The HTML reader keeps its original interactions. Download and extract the ZIP and open `START_HERE.html`, then select California. The unchanged Washington file and shared pages are included only to keep the existing navigation usable. They were not revised in this task. To open only California, use `books/CA_California_Practice_Book.html` with the surrounding folders intact.

The before/after register is `data/EXAMPLE_CHANGE_REGISTER_1000.csv`. Technical evidence is in `validation_report.json` and `browser_validation.json`. Previous versions and the original upload are preserved.
